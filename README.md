# 智慧校园学工管理系统 · 演示版

本仓库收录智慧校园学工管理系统的前端演示页面（纯静态 HTML，无需后端，浏览器直接打开即可）。

## 演示文件

| 文件 | 说明 |
|------|------|
| [学工系统_演示版v4.html](学工系统_演示版v4.html) | PC 端管理后台演示（学籍异动、奖助学金、宿舍、个人中心等）|
| [手机端演示_v2.html](手机端演示_v2.html) | 移动端（学生/辅导员）演示 |

## 本地预览

直接双击 HTML 文件用浏览器打开；或在目录下启动本地服务：

```bash
python3 -m http.server 9001
# 浏览器访问 http://localhost:9001/
```

## 模块概览（PC 端）

- 学籍异动：转专业、结业转毕业、保留/恢复入学资格、留降级、信息变更、离校通知单等全流程审批与导出单
- 奖助学金、评奖评优、勤工助学、纪律处分
- 公寓管理、基础资源与系统管理
- 个人中心：基本信息维护、手写签字上传、修改密码

> 演示数据均为模拟数据，仅用于功能与流程展示。
