## 🔑 核心业务逻辑

### 1. 数据来源与核心流程
- **新生档案**：迎新系统自动同步新生基础信息（姓名、考生号、身份证、院系、专业、班级、录取批次）
- **学号生成**：现场报到确认完成后，由系统根据学号生成规则自动生成（不再提前分配）
  - 支持多种规则：常量型（固定前缀）、关联条件（按院系/专业）、排序型（按成绩/字母序）
  - 批量生成：按院系、专业、批次筛选批量生成学号
  - 手动调整：支持单个学生学号修改，带连续性警告
- **宿舍选择**：学生在线选择宿舍（Step 4）
  - 宿舍楼可视化选择（1号楼-男生、2号楼-女生、3号楼-男生）
  - 楼层房间网格布局，实时剩余床位显示
  - 床位确认后锁定（前端完成，待后端对接宿舍系统API）
- **一卡通办理**：现场报到时办理（Step 7）
  - PC后台录入一卡通号（8-12位）+ 初始密码
  - 领取状态跟踪（未制作/未领取/已领取）
  - 领取人签名确认，领取进度统计
  - 数据导出功能（前端完成，待后端硬件集成）
- **学年批次**：迎新系统同步批次配置（单招/3+2/普通批次、招生计划人数）
- **院系专业**：迎新系统同步组织架构（院系、专业、学制、招生计划、已报到人数）
- **EMS单号**：从邮寄系统获取通知书邮寄状态和物流单号
- **缴费状态**：财务系统实时回传缴费信息

### 2. 学生登录方式
- **首次登录**：考生号或身份证号 + 默认密码（身份证后6位）
- 登录后可修改密码

### 3. 缴费流程
- 查看费用明细 → 点击"前往张家口银行缴费" → 跳转外部链接 → 缴费完成后1-5分钟同步到系统
- 支持绿色通道申请（先入学后缴费）
- 可配置：是否强制缴费后才能生成二维码

### 4. 分班管理
- 基于已报到学员进行预分班
- 支持自动分班（按专业/成绩/性别比例）
- 支持手动调整分班结果
- 可在注册前进行分班

### 5. 宿舍管理（不在迎新系统）
- **已从迎新系统中移除**
- 宿舍由独立的宿舍管理系统负责
- 学生端新增"选择宿舍"步骤（Step 4），在线选择宿舍床位
- 教职工端不进行宿舍分配

### 6. 学号生成机制（重要变更）
- **生成时机**：现场报到确认完成后自动生成
- **生成规则**：由PC后台"学号管理模块"配置生成方案
- **显示规则**：
  - 报到前：学生端显示"待现场报到后生成"
  - 报到后：教职工扫码确认→系统自动生成学号→回显给学生
- **二维码标识**：使用考生号而非学号

### 7. 一卡通办理流程
- **办理时机**：现场报到确认完成后
- **办理流程**：Step 7 - 到指定窗口办理校园一卡通
- **状态跟踪**：PC后台可查看一卡通领取状态

## 📋 系统边界说明

### ✅ 迎新系统PC后台负责
1. **数据同步**（从迎新系统同步新生档案、学年批次、院系专业）
2. 基础配置（报到步骤自定义、必填/选填设置）

4. 学生在线报到（登录、完善信息、缴费、生成凭证）

2. **学年批次新增/编辑**（由迎新系统维护，PC后台只读取）
3. **院系专业新增/编辑**（由迎新系统维护，PC后台只读取）
4. **通知书生成与打印**（招生系统负责）
5. **通知书邮寄**（招生系统对接邮政EMS）
6. **学费收缴**（财务系统负责，迎新系统仅查询状态）
7. **宿舍管理**（独立的宿舍管理系统负责）
8. **军训管理**（独立系统负责）
